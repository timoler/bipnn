# MIS 建模、训练配置与验证

这是基于公开 BIPNN 思路的毕业论文实现，不是原论文全部实验复现。仅考虑无权、非空超边的有限超图，节点总数显式给出，允许孤立节点。重复超边合并，超边内部重复节点报错。下方 32 维网络描述初始小实例配置，2026-10-18 的公开网络适配和受控协议另见末节。

## 两种定义

弱独立集要求每条超边不能全部被选中：sum(x_i, i in e) <= |e|-1。

强独立集要求每条超边最多选一个节点：sum(x_i, i in e) <= 1。

对于超边 {0,1,2}，弱独立集最大能选两个，强独立集最大能选一个。命令行必须显式指定 definition，暂不替用户决定论文的最终定义。

## 能量函数

弱独立集：E(x) = -sum_i x_i + lambda * sum_e product(x_i, i in e)。

强独立集：E(x) = -sum_i x_i + lambda * sum_{(i,j) in P} x_i*x_j，其中 P 是同一超边内的无重复节点对集合。

无权情形下取 lambda > 1。如果二元解不可行，从一个违反约束的超边或节点对中去掉一个选中节点，目标奖励项最多增加 1，惩罚项至少减少 lambda，其他惩罚不增加，因此能量严格下降。全局最小点必然可行，可行点的能量为负的独立集大小。此论证只针对二元全局最优解，不保证神经网络训练或简单阈值化找到可行解。

弱独立集含大于二阶的超边时，当前直接优化 PUBO，没有声称实现 QUBO 降阶。强独立集的能量天然为二次形式。HGNN+ 输入使用目标多项式各项对应的超边，包括节点奖励对应的单节点超边，以保留孤立节点。

## 训练与解码

使用 DHG 提供的 HGNNPConv，两层宽度 32、无 Dropout／BatchNorm，接线性层与 Sigmoid。节点输入为固定种子的随机特征，每个实例单独优化，Adam 学习率 0.01。

使用公开 BIPNN 的关联矩阵乘积求值思路，并显式统一设备。对概率 p 计算多项式损失，加入线性升温的二值化项；默认 200 轮，惩罚系数 2，二值化项最终系数 0.1。这些是验证配置，不是论文最佳参数或原论文复现配置。

输出先按 0.5 阈值化，记录原始解大小与可行性。若存在冲突，优先删除冲突中概率最低的节点；随后按概率顺序贪心扩充。最终解保证可行且极大，不保证最大。单独报告该后处理，不能把后处理带来的收益全部算作网络贡献。

## 评价边界

- 精确枚举只用于最多 22 个节点的正确性实例；初始演示为 12 个节点。更大实例使用 MILP 的可行解与上界，只有求解器证明最优时才报告最优值。
- 对照包含低度优先贪心、穷举最优解与 SciPy/HiGHS 二元线性规划；不是完整的论文基线集合。
- HiGHS 直接最大化节点数，分别使用 sum(x_i)<=|e|-1 或 sum(x_i)<=1 的原始约束，不经过 PUBO 惩罚。默认求解时间上限 30 秒、相对 gap 目标为 0，单独保存求解状态，只有 status=0 才记录为证明最优。
- 神经方法总计时包含网络／优化器和目标结构构建、特征初始化、训练、最终预测与后处理；不含包导入、实例文件读取和结果文件写入。首次运行可能包含库初始化开销。
- 每次从指定种子重新创建网络和优化器；不复用前一次训练权重。GPU 结果不声称跨硬件逐位一致。
- JSON 保存具体实例、种子、配置、源码哈希、连续能量、原始解和最终解。
- 当前稠密关联矩阵主要适合验证，尚未评估大规模显存与数值稳定性。

## 正确性测试

测试涵盖两种定义区别、孤立节点、单节点超边、无超边实例、强独立集与团展开可行性一致性、随机小实例穷举能量等价、修复解可行及极大、矩阵化损失值与梯度和直接计算一致，以及短 CPU 训练。另将 HiGHS 解与枚举结果比较，并验证 32 节点的可解析配对实例。

## 2026-10-18 的配置扩展

固定步数诊断采用作者未修改的 `src.models`、`src.train` 与 `src.loss`：输入 1024 维、隐层 1024／512、BatchNorm、学习率 1e-4、1600 步。公开封装的 LINEAR 不识别示例传入的 `drop_rate=0.5`，实际 Dropout 为 0；保留此行为。此批同时改变多项设置，只作为配置诊断，不能单独归因宽度或退火。详见 [公开配置诊断](public-preset-20261018.md)。

新受控协议将旧结果作为开发数据，另外生成验证图与测试图，仅比较输入／隐层宽度 256 与 1024 及退火开关；两种宽度同时改变输入随机特征维度与网络容量。约 5 秒的构建与训练目标下，CRA 按时间进度从 -1 升到 0.6，替代原固定步数日程。末次解码额外计入实际总耗时，并单独保留初始输出、修复与扩充阶段。协议见 [experiments/controlled-20261018.json](../experiments/controlled-20261018.json)。

新实现用索引乘积求同一 PUBO 损失，减少稠密矩阵的存储；数学和数值梯度核验不等于保证浮点训练轨迹相同。性能应分别报告弱／强定义、微内核及整网范围。强分支的消息传播图由唯一冲突点对与奖励单点构成，因此不能把它表述为保留原始高阶消息结构。

对照扩展为低度贪心、相同解码器的随机单次／重启、SCIP 加贪心初解。后者可扣除 Python 构建时间，使用近似总时间目标；所有实际耗时和最优状态均保存。真实数据版本与约束冗余另见 [来源审计](data-provenance.md)。
