# 毕业论文工作范围与完成标准

更新于 2026-10-18。以完成可检查、可复现的硕士毕业论文为目标，不把发表新的顶级会议方法作为必要条件。学校与导师最终认定工作量；下面把可以交付的工作具体化。

## 建议的正文主线

暂以弱独立集为主线：一条超边不能全部选中，保留真正的高阶约束；强独立集作为定义辨析与补充实验：每条超边最多选一个节点。两种定义已经分别实现和验证，不能将它们的解大小混在一张排名表中。最终与导师核对用词时，已有结果可以支持任一方向。

方法准确表述为“基于 BIPNN 的超图最大独立集适配与实验研究”。继承的 HGNN+ 架构、PUBO 连续优化及 CRA 思路应引用 Bai 等人的 NeurIPS 2025 论文。原论文主要考察 Max-Cut，本文的 MIS 目标、可行解处理、计算表示比较和 MIS 对照实验必须与原论文区分。

这是逐实例无监督优化：对每张待求解超图重新初始化并优化网络。验证集用于选超参数，测试集用于评估选定配置在新实例上的求解表现；不能写成一个预训练模型对所有测试图直接推理，也不能用监督分类的训练准确率衡量。

## 可以构成论文内容的五项具体工作

1. **建模与正确性。**给出两种独立集的整数规划、弱定义的高阶惩罚和强定义的节点对惩罚；说明无权情形惩罚系数大于 1 的二进制最优可行性证明，以及神经优化不保证达到全局最优。用枚举、MILP、梯度检查核验实现。
2. **求解流程。**描述超图网络、节点特征、逐实例优化、训练输出约定、阈值化、修复及补点。分别报告各阶段的可行性与解大小，避免把后处理收益全部归因于网络。
3. **计算实现。**比较稠密关联矩阵与索引乘积表示。数学目标相同，比较数值梯度、表示存储、前后向耗时和额外峰值显存。当前结果支持显存改善，但弱问题的索引内核更慢；不能据此写成所有场景加速，更不能直接把微内核倍数当作整网加速倍数。
4. **受控实验。**在独立验证图上比较网络宽度及退火开关，按预先写好的规则锁定配置。随后用新生成种子进行测试，与低度贪心、相同解码器的随机分数／随机重启、SCIP 加贪心初始解比较。按图先平均训练种子，再汇总实例，保存负结果和实际耗时。
5. **真实数据。**使用有完整导入审计的 Cora、High、Primary 公开仓库版本，核验文件头、节点编号、数量、原始哈希及约束结构。Cora 与论文表格不同，High／Primary 的高阶弱约束大多冗余，这些限制应进入结果解释。

## 本轮与后续的完成标准

本轮交付计算等价性微基准、验证／测试分离的短预算对照、三个真实数据集结果及可复现报告。所有测试实例保留具体选中节点，不能只保留一个最好分数；源码与配置哈希绑定，修改后使用新结果目录。

下一轮先根据本轮误差来源确定实验，而不是同时更换模型、学习率和退火：

- 若短预算没有充分收敛，扩展 5／15／30 秒的求解质量曲线，基线同步扩展预算；保留各预算完整结果。
- 若原始输出不可行或为空，分开检查惩罚系数、退火日程与修复贡献；每次只改变一个因素。
- 若大实例瓶颈在 CPU 解码，保持节点处理顺序和最终解一致，单独比较邻接计数实现与现有可行性检查的耗时。
- 计数式解码投入下一批求解实验时，网络、随机单次和随机重启统一使用同一实现；本轮冻结批次保持原实现。随机重启在相同时间内可能因此完成更多试次，所以不能直接沿用旧对照分数宣称新的整网优势。
- 若要声称大规模优势，再加入 1000／2000 节点及多种关联度；现有 1000 节点损失微基准不能代替完整求解实验。

达到上述标准后，就有材料写方法、实现和实验分析章节；引言、相关工作、总结及学校格式整理可以并行推进。无需先为“创新”堆叠未经验证的新模块。若结果显示传统方法更强，应据实解释质量、时间、显存和约束结构之间的关系。

建议正文顺序：绪论与相关工作；问题定义和 BIPNN 基础；MIS 建模与求解流程；计算实现与实验分析；总结。高阶转二次降阶只有在实际采用并实验比较时才作为独立方法写入，避免开题报告提过、正文却没有实现的内容。
