| bat_graph.txt、citeseer_graph.txt、uat_graph.txt、test.txt | ? ? | 有占位首行，节点总数不能只凭该首行确定 |

原始图文件还包含类似 0 0 的自环记录。MIS 对自环、重复节点及单节点超边的语义需要明确后再转换，不宜直接复用 Max-Cut 的清洗方式。

目前 mis 的 JSON 输入要求显式提供 n 和 edges，保证验证实例的节点总数不会因重编号被悄悄改变。正式接入真实数据前，应保存原始标签映射、数据来源和清洗规则。上述行数是文件记录数，不等同于去重后的超边数。
