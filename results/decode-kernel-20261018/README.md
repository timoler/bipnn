# 等价解码实现的 CPU 对照

2026-10-18 的完整实现基准已完成：Cora、High、Primary 三个固定公开仓库实例 × 弱／强 MIS × 随机种子 0、1、2，共 **18 个案例**。每个案例中，两种实现分别计时 **3 次**，合计 **108 条计时记录**；每方法另有一次不计时的预热。所有记录的阈值解、修复解、最终解及阶段统计均完全相同，最终逐节点解也与原策略一致。

旧实现为 `controlled.decode_stages`，新实现为 `fast_decode_stages`。新实现使用节点与超边的关联表、当前选中数量及最小堆，保留“阈值 ≥ 0.5、从全部冲突点中删除分数最低者、按分数从高到低扩充”的确定性策略和节点编号的同分排序。每次新实现调用都重新构造关联索引，其构造时间计入耗时。**没有改变求解策略、解的质量或当前冻结实验使用的解码器。**

| 数据 | 定义 | 旧实现中位耗时 / ms | 新实现中位耗时 / ms |
|---|---|---:|---:|
| Cora | 弱 | 678.52 | 3.51 |
| Cora | 强 | 1262.07 | 3.81 |
| High | 弱 | 2547.76 | 12.90 |
| High | 强 | 2893.04 | 14.50 |
| Primary | 弱 | 3013.39 | 28.58 |
| Primary | 强 | 3628.26 | 16.80 |

表中先对同一案例的 3 次重复取中位数，再对 3 个种子取中位数。加速比另在同一案例中以“旧中位耗时／新中位耗时”配对计算：18 个案例的中位数为 **186.33 倍**，几何平均为 **170.59 倍**，范围为 **49.09–338.78 倍**；不应以表中跨种子汇总数相除代替配对统计。这里只作描述，没有显著性检验，也未删除慢记录。

输入是 `random.Random(seed)` 生成的逐节点均匀随机分数，同一案例的两个方法使用完全相同的列表；同一数据与种子也在弱／强定义之间复用分数。**这些分数不是训练后的网络输出**，随机阈值集合的冲突数量和修复工作量可能与网络输出明显不同。耗时只涵盖 CPU 解码，不能把该速度比用于声称神经网络训练或完整求解过程加速，也不能据此推断其他数据规模上的倍数。基准在本轮训练全部结束后运行，串行 Python 解码并把相关数值库线程设为 1；桌面后台任务和 CPU 亲和性未控制，全部实际墙钟与 CPU 耗时均保留。

`manifest.json` 保存协议、环境、实例与源码哈希，`instances/` 保存带原始标签映射的实例，`cases/` 保存 18 个案例的完整输入分数、全部 108 次逐阶段输出和计时，`summary.json` 保存完整汇总。原始数据的数量差异及来源边界见 `docs/data-provenance.md`，尤其 Cora 应称为 BIPNN 公开仓库版本。
